# 綽貓喵・可愛相機（初版）

## 開啟方式
- 相機功能需要在 **HTTPS 網站** 或 `localhost` 執行，並允許瀏覽器使用相機。
- 可先在電腦用本機伺服器測試；直接雙擊 `index.html` 時，瀏覽器可能不允許相機。
- 手機瀏覽器對相機、前後鏡頭與檔案存取的支援可能略有不同。

## 初版功能
- 開啟／關閉相機、切換前後鏡頭。
- 拍照、載入本機照片。
- 加入內建角色 PNG、匯入自訂透明 PNG。
- 拖曳貼圖、拉右下角調整大小、點選 × 刪除。
- 加入文字，可選字體、顏色與大小。
- 匯出 PNG；介面框、按鈕與綽貓介面角色不會匯出。
- 自訂 PNG 會嘗試保存在瀏覽器 IndexedDB 中。

## 常見修改位置
- `css/style.css`：主要顏色、按鈕外觀、介面高度、綽貓位置／大小。
- `css/layout.css`：手機直向／橫向與較大螢幕版面。
- `css/editor.css`：貼圖選取框、縮放把手與文字外觀。
- `js/camera.js`：相機開關、前後鏡頭設定。
- `js/stickers.js`：內建貼圖清單、PNG 匯入、拖曳與縮放行為。
- `js/text-tool.js`：文字工具。
- `js/photo-export.js`：匯出照片的合成方式。
- `js/app.js`：按鈕事件、拍照後自動關閉相機等整體流程。

## 重要說明
- `assets/interface/frame-top.png` 和 `frame-bottom.png` 是操作介面裝飾，不會放進匯出照片。
- `assets/characters/` 內的角色圖片，以及由使用者加入的貼圖，會成為照片內容。
- `frame-polaroid.png` 和 `deco-ribbon.png` 暫時沿用你提供的介面素材作為可選貼圖示範；日後可換成真正的照片裝飾 PNG。
- 這是第一版原型，建議先在手機和電腦各測試一次，再依實際畫面調整 CSS 數值。
